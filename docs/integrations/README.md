# Integration Documentation

[`TRINO.md`](TRINO.md) records the completed Trino requirements research and is
the current input to public API design. It distinguishes observed Trino behavior
from proposed library APIs and from work that has actually been implemented.

[`JVM_UNICODE.md`](JVM_UNICODE.md) records the implemented policy and design for
deriving Unicode data from the executing JVM. The intentional upstream
difference is recorded in `RE2_DECISIONS.md`.

Implementation status remains authoritative in
[`RE2_TASKS.md`](../../RE2_TASKS.md).
