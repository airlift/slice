# Audit Documentation

[`PROCEDURES.md`](PROCEDURES.md) defines the current audit and
optimization-verification process. Reusable report formats are under
[`templates/`](templates/).

The [`history/`](history/) directory contains dated reports and their detailed
evidence. Findings from those reports are current only when they remain open in
[`RE2_TASKS.md`](../../RE2_TASKS.md).
