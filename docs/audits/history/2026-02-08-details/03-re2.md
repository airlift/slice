5. Java does not log errors; C++ logs with ABSL_LOG
6. Java DFA API returns long values; C++ uses output parameters
7. Java number parsing is implemented manually; C++ uses strtol/strtoul family
8. Java uses record types for return values; C++ modifies parameters in place
9. Java uses double-checked locking; C++ uses absl::call_once
